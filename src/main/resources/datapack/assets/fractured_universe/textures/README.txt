Папки для кастомных текстур события FracturedUniverse

Важно:
- Текстуры и модели загружаются клиентом через resourcepack.
- Эти папки даны как эталонная структура рядом с datapack-контентом.

Структура:
- assets/fractured_universe/textures/sky   -> текстуры неба (градиенты, трещины, звезды)
- assets/fractured_universe/textures/block -> текстуры кастомных блоков и осколков
- assets/fractured_universe/textures/item  -> текстуры предметов/артефактов
- assets/fractured_universe/models/block   -> модели блоков
- assets/fractured_universe/models/item    -> модели предметов
