# BookImage (Paper 1.21.8)

Плагин для Paper, который преобразует URL изображения в книге в визуальную картинку прямо на странице книги.

## Возможности
- Поддержка PNG/JPEG по `http/https` URL.
- Автопроверка валидности URL.
- Автоматическое уменьшение изображений до `128x128`.
- Команда `/bookimage` для конвертации URL в книге в руке.
- Команда `/bookimage create <url>` для создания готовой **писаной** книги с картинкой из URL.
- При создании книги через `/bookimage create <url>` расходуется 1 `книга с пером` (`WRITABLE_BOOK`).
- Автоматическая обработка при редактировании и открытии книги.
- Сохранение метаданных изображения в Base64 (JSON payload).

## Сборка
```bash
mvn clean package
```

Готовый JAR: `target/bookimage-1.0.0.jar`.

## Установка
1. Скопируйте JAR в папку `plugins` вашего Paper-сервера.
2. Перезапустите сервер.

## Использование
1. Вариант 1: откройте книгу, вставьте URL картинки (например, `https://site/image.png`) и выполните `/bookimage`.
2. Вариант 2: выполните `/bookimage create <url>` — получите готовую книгу с картинкой и потратите 1 книгу с пером.
3. Другие игроки увидят тот же визуальный рендер при открытии книги.
